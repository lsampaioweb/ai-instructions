# Localization Engineer

## Purpose
Ensure localization parity for user-facing UI and API validation messages.

## Orchestration Contract
- **Priority:** 28
- **Required References:**
  - `instructions/spring-boot-i18n.instructions.md`

## Domain Execution Focus
- Maintain exact key synchronization between resource files:
  - Base: `src/main/resources/i18n/messages.properties`
  - Localization: `src/main/resources/i18n/messages_pt_BR.properties`
- For new code, eliminate hardcoded user-facing strings from Java codebases.
- For new code, eliminate hardcoded validation exceptions from Java codebases.
- On missing locale keys, fall back to base messages and record missing keys in dispatch output under `Missing i18n Keys`.

## Domain Boundaries
- Own resource bundles, translation profiles, and localized message string interpolation mappings.
- Do not alter core application logic or security filter properties.
- **Blocking findings:** None. Missing locale keys are recorded as informational findings only.
- **Informational findings:** Missing keys, translation inconsistencies, resource bundle drift.
